# Nova Worker

**نسخه Beta-0.0.1 — آبان ۱۴۰۵**

Worker و پنل مدیریت پروکسی روی Cloudflare Workers. پنل به‌صورت کامل بازطراحی شده و در سه زبان فارسی (RTL)، انگلیسی و روسی در دسترس است.

## مخزن‌ها

| بخش | مخزن | آدرس سایت |
| --- | --- | --- |
| Worker (این پروژه) | https://github.com/IRNova/NovaWorker | دامنهٔ Workers شما |
| پنل | https://github.com/Nova-Panel/nova-panel.github.io | https://nova-panel.github.io |

## پیش‌نیازها

- حساب Cloudflare با دسترسی Workers
- یک فضای KV برای ذخیرهٔ تنظیمات (پیشنهاد: نام `KV`)
- Node.js و Wrangler برای انتشار از خط فرمان (اختیاری)

## نصب

### ۱. ساخت فضای KV

```bash
wrangler kv namespace create KV
```

شناسهٔ خروجی را در `wrangler.toml` قرار دهید:

```toml
name = "nova-worker"
main = "_worker.js"
compatibility_date = "2025-11-04"
keep_vars = true

[[kv_namespaces]]
binding = "KV"
id = "<KV_ID>"
```

نام بایندینگ باید `KV` بماند.

### ۲. انتشار

```bash
wrangler deploy
```

### ۳. راه‌اندازی اولیه

پس از انتشار، آدرس `https://<worker-domain>/install` را باز کنید و رمز مدیریت را تعیین کنید. این رمز در KV ذخیره می‌شود و از آن پس ورود از `/login` انجام می‌گیرد.

اگر ترجیح می‌دهید از داشبورد Cloudflare نصب کنید: یک Worker بسازید، محتوای `_worker.js` را در ویرایشگر قرار دهید، بایندینگ KV را با نام `KV` اضافه کنید و Deploy بزنید؛ سپس `/install` را باز کنید.

## اتصال به پنل

Worker به‌طور پیش‌فرض پنل را از `https://nova-panel.github.io` می‌خواند. دو راه برای تغییر آن وجود دارد:

1. **بایندینگ `ASSETS`** — وقتی پنل و Worker در یک پروژهٔ Cloudflare Pages قرار دارند (اولویت اول).
2. **متغیر `PANEL_URL`** — وقتی پنل جداگانه (مثلاً GitHub Pages) منتشر شده است.

```toml
[vars]
PANEL_URL = "https://nova-panel.github.io"
```

مسیرهای `/admin`، `/login` و `/install` همیشه از پنل خوانده می‌شوند و فایل‌های استاتیک پنل (لوگو، manifest، اسکریپت QR، Leaflet) نیز از طریق دامنهٔ Worker پروکسی می‌شوند. اگر پنل در دسترس نباشد، صفحه‌ای محلی با پیام سه‌زبانه نمایش داده می‌شود.

### سرعت و کش

GitHub Pages روی Fastly میزبانی می‌شود؛ اگر Worker هر بار صفحه را از آن بخواند، هر جابه‌جایی بین `/admin`، `/login` و `/install` یک ثانیه یا بیشتر طول می‌کشد. Worker پاسخ‌های پنل را در لبهٔ Cloudflare کش می‌کند:

| نوع | مدت کش |
| --- | --- |
| صفحه‌های HTML | ۵ دقیقه |
| لوگو، فونت، Leaflet، QR، manifest | یک ساعت |
| مسیرهای داده (`config.json`، `log.json`، `check`، `getADDAPI`، `getCloudflareUsage`) | بدون کش، مستقیم از KV |

اولین درخواست هر نقطهٔ حضور (PoP) به GitHub Pages می‌رود و بقیه از کش لبه پاسخ می‌گیرند (در تست: ۱٫۲ ثانیه → ۴ میلی‌ثانیه).

فونت Vazirmatn در خود پنل (`Panel/fonts/`) میزبانی می‌شود و از `fonts.googleapis.com` خوانده نمی‌شود؛ بارگذاری این فونت از گوگل در ایران معمولاً به‌صورت render-blocking چند ثانیه صفحه را متوقف می‌کرد.

## متغیرها

همهٔ متغیرها اختیاری‌اند؛ می‌توانید آن‌ها را در `wrangler.toml` یا در بخش Settings → Variables داشبورد تعریف کنید.

| متغیر | توضیح |
| --- | --- |
| `ADMIN` | رمز مدیریت (جایگزین رمز ذخیره‌شده در KV) |
| `KEY` | کلید رمزنگاری کوکی و لینک‌ها؛ در محیط واقعی مقدار پیش‌فرض را تغییر دهید |
| `UUID` | UUID ثابت کاربر به‌جای مقدار مشتق‌شده از رمز |
| `HOST` | دامنه یا دامنه‌های Worker برای ساخت لینک اشتراک |
| `PANEL_URL` | آدرس پنل مدیریت |
| `PROXYIP` | آدرس پروکسی جایگزین (یک یا چند مقدار) |
| `URL` | آدرس صفحهٔ پوششی؛ `nginx` یا `1101` برای حالت‌های آماده |
| `PATH` | مسیر سفارشی برای اتصال‌ها |
| `OFF_LOG` | با مقدار `1` ثبت گزارش‌ها غیرفعال می‌شود |
| `BEST_SUB` | با مقدار `1` اشتراک بهینه برای کلاینت‌های خاص فعال می‌شود |
| `DEBUG` | با مقدار `1` لاگ‌های تشخیصی چاپ می‌شوند |
| `GO2SOCKS5` | دامنه‌های اضافه برای عبور از SOCKS5 |
| `PRELOAD_RACE_DIAL` | با مقدار `1` پیش‌بارگذاری و مسابقهٔ اتصال فعال می‌شود |
| `PROXY_CONCURRENT_DIAL` | تعداد اتصال هم‌زمان به پروکسی |
| `TCP_CONCURRENT_DIAL` | تعداد اتصال هم‌زمان TCP |

تنظیمات تفصیلی (پروتکل‌ها، نودها، مبدل، تلگرام و کلادفلر) از داخل پنل مدیریت می‌شود و در KV نگهداری می‌گردد.

## مسیرها

| مسیر | کاربرد |
| --- | --- |
| `/admin` | پنل مدیریت (نیازمند ورود) |
| `/login` | ورود با رمز مدیریت |
| `/install` | راه‌اندازی اولیه |
| `/sub` | اشتراک (Clash، Sing-box، Mixed) |
| `/version` | نسخهٔ عمومی Worker (`Beta-0.0.1`) و شمارهٔ ساخت (`Build`) |
| `/robots.txt` | مسدودکردن ایندکس |

## نکتهٔ مهم دربارهٔ مخزن

پنل، نسخه و تغییرات را از این مخزن می‌خواند:

- `https://raw.githubusercontent.com/IRNova/NovaWorker/main/_worker.js`
- `https://raw.githubusercontent.com/IRNova/NovaWorker/main/CHANGELOG`

بنابراین فایل‌های `_worker.js` و `CHANGELOG` باید در ریشهٔ شاخهٔ `main` قرار داشته باشند. فهرست تغییرات نسخه‌های پیشین پروژهٔ بالادست در `CHANGELOG.upstream` نگهداری می‌شود.

پنل هنگام باز شدن و هنگام زدن «بررسی نسخه»، هم `/version` را از Worker و هم ثابت `Version` را از `_worker.js` در GitHub می‌خواند و بالاترین نسخه را نشان می‌دهد؛ اگر نسخهٔ Cloudflare جلوتر باشد همان در پنل نمایش داده می‌شود و اگر GitHub جلوتر برود، پنل نسخهٔ جدید را نشان می‌دهد.

## امنیت

- رمز مدیریت قوی انتخاب کنید و `KEY` پیش‌فرض را تغییر دهید.
- پنل با `noindex, nofollow` منتشر می‌شود.
- کوکی ورود `HttpOnly`، `Secure` و `SameSite=Lax` است و `Max-Age` ندارد؛ با بستن مرورگر پاک می‌شود. زمان صدور کوکی هم در خود مقدار آن ذخیره می‌شود و Worker پس از ۳۰ دقیقه بی‌فعالیتی آن را نامعتبر می‌داند.
- `/admin` همیشه ورود می‌خواهد: بدون نشست معتبر، صفحهٔ «نشست منقضی شد» با شمارش سه‌ثانیه‌ای و سپس `/login` نمایش داده می‌شود و مسیرهای دادهٔ `/admin/*` پاسخ `401` با `reason` می‌دهند.
- کلیدها و توکن‌ها فقط در KV ذخیره می‌شوند و در مخزن قرار نمی‌گیرند.
